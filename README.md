# BehaviorTreeSandbox
Behavior tree sandbox environment

Small sandbox project to explore behavior trees. Features simple chase, search and patrol behavior. Made with Unreal Engine editor 5.8.0.
Player speed is increased so it is easier to escape the guard and check out the search logic. For a small but comprehensive demo see this video:
https://youtu.be/Z0vqSoe2r1Y?si=UwcxREwCYNB7c-TG
